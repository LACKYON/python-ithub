РЕШЕНИЯ КОНТРОЛЬНЫХ ТОЧЕК — ЯЗЫК ПРОГРАММИРОВАНИЯ PYTHON

Решения подготовлены по формулировкам КТ на странице дисциплины. В курсе отмечено, что он архивный; отправка ответов из системы недоступна. Ничего в личный кабинет не загружалось.

КТ1 — «Глухая бабушка»
Файл: КТ1_глухая_бабушка.py
Три отдельные строки «ПОКА!» завершают разговор. Если пользователь вводит другую фразу, счётчик прощаний сбрасывается. Для громких реплик выбирается случайный год от 1930 до 1950.

КТ2 — «Виселица»
Папка kt2_hangman: запустить main.py. Код игры находится в hangman.py, слова — в words.txt, этапы рисунка — в отдельных файлах hangman_drawings. В main.py только импорт и вызов функции, как требует задание.

КТ3 — «Парсинг CSV»
Папка kt3_csv: запустить main.py. В трёх функциях обработки данных используются map/filter без циклов. books.csv приложен как исходный каталог.
get_books(filename) читает каталог; filtered_books(books, text) оставляет совпадения в названии и объединяет название с автором; books_value(books) возвращает кортежи ISBN и стоимости остатка.

КТ4 — «ООП: User и SuperUser»
Папка kt4_oop: запустить main.py. Есть наследование, свойства, счётчики классов и сравнение по grade. Сеттеры login и grade выводят требуемые сообщения, потому что в Python результат присваивания через property-setter вызывающий код получить не может.

КТ5 — «Напоминалка ToDo»
Папка kt5_todo: запустить main.py. Можно добавлять, показывать, отмечать выполненными и удалять задачи. Они сохраняются в tasks.txt в формате название|дата|статус. Цвета: красный — срок прошёл, жёлтый — сегодня, зелёный — в будущем.

Запуск: открыть терминал в соответствующей папке и выполнить python main.py (для КТ1 — python КТ1_глухая_бабушка.py).
